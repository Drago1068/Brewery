# Phase 0 Acceptance Gate

## Gate Decision
APPROVED FOR CONTROLLED IMPLEMENTATION

## Required Before Phase 1 Begins
- Architecture baseline present in repository.
- Codex reads baseline before coding.
- Actual NAS/development target confirmed.
- Repository location chosen.
- Secrets strategy established.
- Backup destination identified.
- Initial supported unit system documented.
- Framework versions selected and recorded.

## Phase 1A Exit Criteria
The first vertical slice must:
- run end to end
- survive browser refresh during active mash timer
- persist measurements
- display target vs actual
- create audit/journal records
- pass automated tests
- produce no material architecture violations

Only then authorize Phase 2.
